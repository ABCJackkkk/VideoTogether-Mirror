一起看视频 iPhone

异地同步看视频，跟 Android 朋友一起看 B 站/YouTube

1 安装 Via 浏览器
App Store 搜索 "Via" 或直接访问：
App Store - Via
2 安装同步脚本
点击下面按钮，Via 会自动弹出安装提示，点"确认"即可。
安装同步脚本
3 开始使用
用 Via 打开任意视频页面（B 站、YouTube 等），右下角会自动出现"一起看"控制面板。
输入房间号加入，跟朋友同步看视频。
提示：每次看视频时，请用 Via 浏览器打开视频页面（不要用 Safari）。 脚本只在 Via 里自动运行。

常见问题

为什么必须用 Via？
iPhone 上 Safari、Edge、Chrome 都不支持装脚本。Via 是少数支持用户脚本的 iPhone 浏览器， 能让脚本在所有视频页面自动运行。
脚本能控制哪些视频？
B 站、YouTube、优酷、本地文件等大部分视频都能控制。 腾讯视频、爱奇艺等带 DRM 加密的可能无法同步。
脚本安全吗？
脚本是开源的，只做两件事：1) 同步播放进度 2) 收发文字消息。 不收集任何数据，不上传任何信息。
